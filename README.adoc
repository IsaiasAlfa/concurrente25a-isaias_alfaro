== Glosario


*1.Programación serial.*

Tipo de programación que sigue una linea recta, no se puede avanzar a la segunda tarea sin antes terminar la primera.

** Ejemplo
* Escuela
* Colegio

*2.Programación concurrente.*

Programación que no es serial.

** Ejemplo
* Se llevan cursos en un mismo ciclo lectivo.

*3.Programación paralela.*

Programación que ocurre en el mismo momento, de forma simultanea.

** Ejemplo
* Ver una película
* Escuchar la película
* Comer palomitas

*4.Concurrencia de tareas.*

Diferentes ejecutantes se encargan de diferentes asuntos.

** Ejemplo
** En una empresa
* Contador
* Recursos humanos
* Informático

*5.Paralelismo de datos.*

Un proceso se divide en muchos "hilos" para aumentar la eficiencia de la tarea.

** Ejemplo
* Renderizado de una película animada en un clúster de computadoras.

*6.Hilo de ejecución.*

Secuencia de instrucciones que se puede ejecutar de forma independiente. 

** Ejemplo
** Cocina
* El chef pone a cocinar carne.
* El chef pone a cocinar pasta.
El chef pone a hervir verduras.

*7.Indeterminismo.*

No se puede predecir como se ejecutan los "hilos", quien se ejecuta antes.

** Ejemplo
* El primer hilo logra cpu despues del segundo hilo y el tercero es el ultimo. 

*8.Memoria privada y compartida.*

Memoria privada es la memoria que posee cada hilo y solo el puede acceder a ella. Véase las variables locales.

Memoria compartida es la memoria que todos los hilos heredan de el hilo que los creó, todos tienen el acceso a esta memoria
Se puede enviar cada memoria por structs y punteros a estos.

*9.Espera activa.*

La espera activa ocurre cuando un hilo se mantiene en ejecución sin hacer trabajo útil, esperando que se cumpla una condición. Esto se considera una mala práctica porque consume recursos de CPU innecesariamente.

** Ejemplo
* Un while que deja a los hilos esperando hasta que cumplan una condición puesta por otro hilo.

*10.Condición de carrera.*

Modificacion concurrente de memoria compartida. Cuando se modifica al mismo tiempo una parte de la memoria por dos o mas hilos.

** Ejemplo
* Un cocinero utiliza una olla para la carne.
* Otro cocinero echa al mismo tiempo leche en la olla.
